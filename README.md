# 💼 Employment Management System - Front-End

A front-end web project for an **Employment Management System**, designed to provide a user-friendly interface for managing employee-related information and HR administrative processes.

This project focuses on the **design and implementation of the user interface and front-end pages** of the application.

---

## ✨ Features

The interface includes several pages related to employee and HR management, such as:

- 👤 Employee profiles
- ➕ Adding employees
- 📄 Employee documents
- 📋 Contracts
- 🏖️ Annual leave
- 🤰 Maternity leave
- 🏥 Sick leave
- 📈 Promotions
- ⚠️ Sanctions
- 📊 Employee evaluation and rating
- 📝 Administrative documents
- 💼 Other HR-related procedures

---

## 🖥️ Project Pages

Some of the main interfaces include:

- `index.html` — Home page
- `profil.html` — Employee profile
- `ajouter-employe.html` — Add employee
- `contrats.html` — Contracts
- `annuel.html` — Annual leave
- `maternité.html` — Maternity leave
- `maladie.html` — Sick leave
- `promotions.jpg` — Promotions interface
- `sanctions.html` — Sanctions
- `rapport-notation.html` — Employee evaluation
- `attestation.html` — Certificates
- `document-promotion.html` — Promotion documents

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

---

## 🎯 Project Objective

The objective of this project was to design and develop the **front-end interface** of an employment management system.

The focus was on:

- Creating a clear and organized user interface
- Designing different HR management pages
- Improving navigation between different sections
- Presenting employee-related information in a structured way
- Creating a consistent visual design across the application
